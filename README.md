# Oficina / Camiseta — Estúdio 3D

Editor local em português para personalizar camisetas no navegador. Inclui modelos de camiseta, manga longa, cropped, moletom, regata, polo e camisa casual; disco de cores; arte enviada pelo usuário; texto; pintura por ponteiro/toque; vistas frente/costas/lateral; zoom; cenários e exportação PNG com as duas faces.

## Desenvolvimento

- Requisitos: Node.js 22+ e pnpm 11.
- Instalação: `pnpm install`
- Prévia: `pnpm dev`
- Build estático: `pnpm build`

O editor não requer login, servidor ou banco de dados. As imagens selecionadas são usadas localmente no navegador e não são enviadas ao servidor.
